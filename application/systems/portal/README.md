# Portal System

This folder contains the source code for the Portal system module of the PRIA application. It is organized into several submodules, each responsible for different features and functionalities.

## Structure

- **code_libraries/**: Shared libraries for controllers, models, and views used across the portal system.
- **common/**: Common controllers, models, and views for reusable logic and components.
- **constants.php**: Contains constant definitions used throughout the portal system.
- **dashboard/**: Handles dashboard-related features, including controllers, models, and views.
- **import_reference/**: Manages import reference functionality with its own controllers, models, and views.
- **reports/**: Responsible for generating and managing reports, with dedicated controllers, models, and views.
- **submitted_document/**: Manages submitted documents, including controllers and views.
- **tasks/**: Handles task management features, with controllers, models, and views.
- **transactions/**: Manages transaction-related features, with controllers, models, and views.

## Usage

Each subfolder typically contains:
- `controllers/`: Business logic and request handling.
- `models/`: Data access and manipulation.
- `views/`: Presentation layer and UI templates.

Refer to each submodule for specific implementation details.
